# Load Ledger

A phone-first lifting log that turns your sets into a weekly report of training load per body part.

- **Log**: start or repeat a workout, add exercises, and enter weight × reps. Last time's numbers show as hints, and "Use these" copies them in. Tap **W** to mark a warm-up set so it doesn't count.
- **Report**: pick a week to see workouts, hard sets and total load compared with the week before. It includes:
  - a front/back body heatmap, shaded by hard sets or by load
  - notes on volume jumps over 30%, muscles over 20 sets, untrained muscles and when to deload
  - a per-muscle table grouped by body part, with 6-week sparklines
  - "Copy as text" for sharing the report
- **History**: past workouts grouped by week. Tap one to edit it.
- **Settings**: kg/lb, the day your week starts, your bodyweight (counted on pull-ups, dips and similar lifts), and your own exercises with main and helper muscles.

How load is counted: an exercise's main muscles get a full set and its helper muscles get half a set (bench press = 1 chest, ½ triceps, ½ front delts). Load = weight × reps, credited the same way.
