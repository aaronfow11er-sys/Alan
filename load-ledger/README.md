# Load Ledger

A phone-first training log for lifting and running. It turns your sessions into a weekly report of load per body part, running volume and effort.

- **Log**: start lifting or log a run. A run records distance, time, average HR and type (easy, long, tempo, intervals, race, recovery), and the app works out your pace.
- **After each session**: rate the whole session's RPE (1–10), add the duration and write notes. RPE × minutes gives a session load figure.
- **Lifting**: start or repeat a workout, add exercises, and enter weight × reps. Last time's numbers show as hints, and "Use these" copies them in. Tap **W** to mark a warm-up set so it doesn't count.
- **Report**: pick a week to see workouts, hard sets and total load compared with the week before. It includes:
  - a Running section with distance, time, average pace and longest run
  - an Effort & notes section with average RPE, session load and each session's rating and notes
  - a front/back body heatmap, shaded by hard sets or by load
  - notes when running distance rises more than 10%, session load jumps 30% or average RPE runs very high, plus muscles over 20 sets, untrained muscles and when to deload
  - a per-muscle table grouped by body part, with 6-week sparklines
  - "Copy as text" for sharing the report
- **Journal**: a daily note with sleep, energy (1–5), soreness (1–5) and free text, a chart of your recent session RPEs, and a day-by-day timeline of notes and sessions.
- **History**: past workouts grouped by week. Tap one to edit it.
- **Settings**: kg/lb, km/mi, the day your week starts, your bodyweight (counted on pull-ups, dips and similar lifts), and your own exercises with main and helper muscles.

How load is counted: an exercise's main muscles get a full set and its helper muscles get half a set (bench press = 1 chest, ½ triceps, ½ front delts). Load = weight × reps, credited the same way.
