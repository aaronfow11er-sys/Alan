# Comeback Board

A phone-first tracker for texting former gym members and new leads.

- **Today**: who's overdue or due for a follow-up, plus people you haven't contacted yet (most recently left first).
- **People**: search and filter everyone by stage (To contact → Texted → Talking → Won back / Not now).
- **Texts**: reusable message templates. `{first}` = first name, `{gym}` = gym name.
- **Add**: add someone by hand, or import a CSV/Excel export from your gym software (duplicates skipped by phone/email).

Tap a person to open their message in Messages (or copy it), then log "I texted them" and pick when to be reminded again.

Live version: https://claude.ai/artifact/6aANZQvygNPNqHvLhMrbwr (data is stored with the artifact on claude.ai).
